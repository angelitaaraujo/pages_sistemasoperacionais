📖 Teoria em Resumo (cap. 14) ▼
Endereços físicos e lógicos (14.4) Físicos são os endereços dos bytes da memória física. Lógicos (virtuais) são os usados pelos processos e pelo sistema operacional; o processador gera endereços lógicos e eles precisam ser traduzidos.
MMU (14.4) Componente de hardware que intercepta os endereços lógicos emitidos pelo processador e envia os endereços físicos correspondentes ao barramento de endereços. Se o acesso não for possível, gera uma interrupção de hardware.
Páginas e quadros (14.7) O espaço lógico é dividido em blocos de mesmo tamanho, as páginas (geralmente 4 KBytes, 4.096 bytes). A memória física é dividida em quadros do mesmo tamanho. Uma página pode estar em qualquer quadro.
Tabela de páginas e PTBR (14.7.1) Cada entrada corresponde a uma página e contém o número do quadro. Cada processo tem sua tabela; a tabela ativa é referenciada pelo registrador PTBR (Page Table Base Register).
Intel 80386 (14.7.1) Endereço lógico de 32 bits = offset de 12 bits (de 0 a 4.095) + número de página de 20 bits. Assim, podem ser endereçadas 220 páginas com 212 bytes cada (1.048.576 páginas com 4.096 bytes cada).
Falta de página e flag Valid (14.7.1, 14.7.2) Páginas não usadas são entradas vazias, sem quadro. Acessá-las (ou usar uma página com Valid = 0) gera uma falta de página (page fault): desvio para o núcleo, que deve tratá-la, abortando o processo ou tomando outra medida.

🧱 Memória virtual por partições
